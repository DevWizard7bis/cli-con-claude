# Mis Notas de CLI con Claude 🚀

Este repositorio es una base de conocimientos personal destinada a documentar comandos de la línea de comandos (CLI), soluciones a problemas técnicos y trucos de terminal.

## 📌 Objetivo
Guardar de forma organizada y legible los comandos proporcionados por Claude para resolver problemas específicos, evitando tener que buscarlos repetidamente y facilitando el aprendizaje del ecosistema Linux/Unix.

## 📂 Estructura de Documentación
Cada archivo `.md` contiene:
- **El comando**: La sintaxis exacta.
- **Explicación**: Qué hace cada bandera o argumento.
- **Ejemplo de uso**: Casos reales de aplicación.
